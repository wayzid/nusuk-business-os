Protecting 3.6M pilgrims with 4 AI agents | All Things Agentic Hackathon

### The Problem
During Hajj, pilgrims face fake QR payments, scams, and language barriers. No trusted verification exists.

### The Solution
4 Autonomous Agents powered by Gemini 2.5 Pro + Google ADK:
1. **Payment Guardian:** Verifies QR codes in real-time
2. **Guidance Agent:** Hajj step-by-step assistance  
3. **Translator Agent:** Real-time translation 10+ languages
4. **Merchant Verifier:** Checks merchant trust score on Google Cloud

### Tech Stack
Gemini 2.5 Pro, Google Agent Development Kit, Cloud Vision, Firebase, Google Cloud, Maps
